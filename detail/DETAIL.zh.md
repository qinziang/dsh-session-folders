# 对话独立文件夹

启用后，在已登记的工作区中新建对话时，会在工作区里创建该对话专属的子文件夹：

```
<对话标题>-<完整会话 ID>
```

只有真正新建的对话会创建文件夹，安装插件前的已有会话不会追溯迁移。对话的自动标题或手动标题变化时，文件夹会同步改名。归档对话时文件夹加上 Windows 隐藏属性，取消归档时移除隐藏属性。

## 空文件夹

如果一轮对话结束时，文件夹里除了 `.dsh-session-folder.json` 标记文件之外没有任何用户文件（例如用户只发了一句“你好”），插件会删除这个空文件夹和对应的 ASCII 联接。下次在这个对话中发送消息时，会在工作目录校验阶段、系统提示和工具开始执行之前重新创建文件夹与联接，避免工作目录回退到工作区根目录。只要文件夹里产生了任何文件，这轮结束后就会保留。

## 非 ASCII 路径兼容

对话的实际工作目录会指向一个 ASCII 路径的连接点（junction）：`%PUBLIC%\dsh-session-folders\aliases\<会话 ID>`，它指向真实的中文对话文件夹。Node、Python、PowerShell 和旧式批处理脚本看到的是纯 ASCII 的工作目录，但所有文件仍实际保存在对话自己的文件夹中。

## 删除对话

永久删除对话时，插件会停止该会话登记的后台任务，尝试终止仍在对话文件夹或 ASCII 联接路径下运行的进程，删除 ASCII 联接，再递归删除真实对话文件夹。删除清理只会在确认会话持久化记录和工作区登记都已消失后执行，因此 Host 正常退出或普通清理不会被误判为删除。

## 标记文件

每个对话文件夹内都会写入 `.dsh-session-folder.json`，记录会话 ID、标题、归档状态和 ASCII 联接路径，便于重启后恢复。这个标记文件本身不会让文件夹被视为“非空”。
